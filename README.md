# Smart Hospital Queue & Patient Flow Intelligence System

A Streamlit demonstration app that estimates hospital waiting time with a Random Forest regression model and presents queue indicators and descriptive analytics.

## Features
- Estimated waiting-time prediction from hospital, department, day, hour, patients waiting, available doctors, emergency cases and holiday status
- Low/medium/high crowd level, queue status and a simple recommendation
- Prediction history during the current Streamlit session
- Analytics by hospital, department and day, plus summary insights

## Tech stack
Python, Streamlit, Pandas, scikit-learn, Matplotlib and Joblib.

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this project directory.
3. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```
4. Train the model and create the model/encoder files:
   ```bash
   python train_model.py
   ```
5. Launch the app:
   ```bash
   python -m streamlit run app.py
   ```

## Important data note
The included `dataset.csv` is **synthetic demonstration data generated to make the project runnable**. It is not real hospital operational data, and the resulting predictions are not clinically validated or suitable for real patient-care decisions. Replace it with appropriately authorized, representative data and retrain/evaluate the model before making any real-world claims.

## Project files
- `app.py` — Streamlit user interface and analytics (saved version from the project conversation)
- `train_model.py` — training script supplied for this runnable package
- `dataset.csv` — synthetic sample data
- `hospital_model.pkl`, `label_encoders.pkl` — generated by `train_model.py`
- `requirements.txt` — Python dependencies
